# Task 2 - JavaScript Projects

This folder contains three small JavaScript projects built for practice and demonstration:

- [01_counter](01_counter) - a simple counter app
- [02_to-do](02_to-do) - a to-do list app
- [03_quiz](03_quiz) - a quiz game with scoring and a high-score board

## How to Run

Each project is a static HTML/CSS/JavaScript app. Open the matching `.html` file directly in a browser.

- Counter: [01_counter/counter.html](01_counter/counter.html)
- To-do: [02_to-do/to_do.html](02_to-do/to_do.html)
- Quiz: [03_quiz/quiz.html](03_quiz/quiz.html)

## Project Overview

### 01_counter

A beginner-friendly counter app for increasing, decreasing, and resetting a numeric value.

Files:

- [counter.html](01_counter/counter.html)
- [counter.css](01_counter/counter.css)
- [counter.js](01_counter/counter.js)

### 02_to-do

A simple task manager for adding and tracking to-do items.

Files:

- [to_do.html](02_to-do/to_do.html)
- [to_do.css](02_to-do/to_do.css)
- [to_do.js](02_to-do/to_do.js)

### 03_quiz

An interactive quiz app that loads questions from JSON, tracks score, saves the latest result, and displays high scores.

Files:

- [quiz.html](03_quiz/quiz.html)
- [quiz.css](03_quiz/quiz.css)
- [game.html](03_quiz/game.html)
- [game.css](03_quiz/game.css)
- [game.js](03_quiz/game.js)
- [end.html](03_quiz/end.html)
- [end.css](03_quiz/end.css)
- [end.js](03_quiz/end.js)
- [highscores.html](03_quiz/highscores.html)
- [highscores.css](03_quiz/highscores.css)
- [highscores.js](03_quiz/highscores.js)
- [questions.json](03_quiz/questions.json)

## Notes

- The quiz uses `localStorage` to keep the most recent score and saved high scores.
- The quiz pages are linked together through the game, result, and leaderboard screens.
- This folder is intended to be opened as a set of plain front-end exercises, not as a build-based project.
